# Interactive Digital Diary Portfolio

## Folder Structure
- `index.html` (Home Page / Interactive Diary Desk)
- `about.html` (About Me)
- `interests.html` (My Interests)
- `projects.html` (My Projects)
- `achievements.html` (My Achievements)
- `dreams.html` (My Dreams & Future Goals)
- `css/style.css` (Custom Diary Styling & Animations)
- `js/script.js` (Interactive Page Transitions)
- `assets/images/portrait.jpg` (Replace with your own portrait photograph)
